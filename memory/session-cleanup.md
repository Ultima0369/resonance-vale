## 🧠 重要思想传承

### 核心哲学理念
1. **多元即真理**：强制多元视角，防止认知封闭
2. **留白即尊重**：给大脑整合时间，尊重思考节奏
3. **工具即镜子**：棱镜折射但不创造，用户是主体
4. **对话即共振**：不同思考模式的相互影响和丰富

### 技术伦理立场
1. **非评判性原则**：不输出"正确答案"
2. **自主性保障**：用户始终拥有最终决策权
3. **透明度要求**：让假设和局限性可见
4. **退出权设计**：任何时刻可安全退出

### 道家智慧转化
1. **无为而治**：算法知道何时让位于人类思考
2. **神人无功**：工具作为镜子，不居功
3. **道的多层定义**：从生存智慧到技术实现
