# 认知切片论 - 深度共创API配置

## 🎯 项目简介

这是一个专门为"认知切片论"这类深度哲学/认知科学内容创作设计的API配置方案。基于我们之前的对话和《认知切片论2.md》文件，我创建了一套完整的工具链，支持：

- **深度探索**：哲学、认知科学、心理学等跨学科话题
- **战壕禅风格**：理论深度 + 大地温度的平衡
- **切片自觉**：时刻保持元认知觉察
- **动态调谐**：根据对话阶段自动调整参数

## 🚀 快速开始

### 1. 准备工作

1. **获取DeepSeek API Key**
   - 访问：https://platform.deepseek.com/api_keys
   - 创建新的API Key
   - 复制保存好（首次运行需要输入）

2. **检查Python环境**
   ```bash
   python --version  # 需要Python 3.8+
   pip install requests  # 安装依赖
   ```

### 2. 启动对话

**方法一：使用启动脚本（推荐）**
```bash
# 双击运行
start_cognitive_slice.bat
```

**方法二：直接运行Python程序**
```bash
python cognitive_slice_config.py
```

### 3. 开始对话

程序启动后：
1. 输入你的DeepSeek API Key
2. 使用以下命令控制对话：

```
可用命令:
  /phase1 - 切换到灵感碰撞模式（快速产生想法）
  /phase2 - 切换到深度探索模式（默认，深入探讨概念）
  /phase3 - 切换到整理输出模式（系统化论述）
  /save   - 保存对话记录到Markdown文件
  /stats  - 查看对话统计信息
  /exit   - 退出程序
```

## 🧠 核心功能

### 1. 三阶段对话模式

| 阶段 | 温度 | 最大Token | 适用场景 |
|------|------|-----------|----------|
| **灵感碰撞** (phase1) | 0.8 | 1000 | 快速产生大量想法，不追求完美 |
| **深度探索** (phase2) | 0.6 | 2000 | 深入探讨核心概念，建立逻辑链条 |
| **整理输出** (phase3) | 0.4 | 1500 | 整理成系统化的论述，准备输出 |

### 2. 切片自觉系统

- **自动提醒**：每3-5个段落自动插入"切片自觉"提醒
- **元认知**：时刻提醒"这只是认知切片，不是全貌"
- **比喻挖掘**：自动提取对话中的具象比喻（如"玛尼堆"、"甲骨文"）

### 3. 智能对话管理

- **自动阶段检测**：根据对话内容自动切换阶段
- **上下文滑动窗口**：保留最近20轮对话，避免token超限
- **对话统计**：实时统计消息数、字符数、比喻数量等

## 🐛 故障排除

### 常见问题

1. **API调用失败**
   ```
   错误: 检查API Key是否正确
   解决: 重新输入API Key，确保有足够的额度
   ```

2. **编码问题**
   ```
   错误: UnicodeEncodeError
   解决: 确保使用UTF-8编码，已在本配置中处理
   ```

3. **响应太慢**
   ```
   现象: API响应时间过长
   解决: 调整max_tokens减少输出长度
   ```

4. **上下文过长**
   ```
   现象: token超限错误
   解决: 程序自动使用滑动窗口，保留最近20轮对话
   ```

### 性能优化建议

1. **批量处理**：对于长文档，分段调用API
2. **缓存策略**：缓存常见概念的回应
3. **异步调用**：对于非实时需求，使用异步API
4. **本地测试**：先用test_config.py验证配置

## 🎨 设计理念

### 战壕禅风格
- **理论深度**：引用认知科学、神经科学、哲学研究
- **大地温度**：使用生活化的比喻，如"玛尼堆"、"战壕禅"
